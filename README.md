# 泳道拆样台(fastq-demux)

测序中心同一泳道的 R1 / R2 / I1 三份**未压缩** FASTQ,按样本索引 CSV 拆出成对读段。
FastAPI + SQLite,逐对流式处理,不整份读入内存。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

本地开发(不需要 Docker):

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8000
# 测试:pip install httpx pytest && python -m pytest tests/
```

## 使用

1. 首页填**运行号**(字母数字开头,可含 `- _ .`),上传 R1、R2、I1 三份未压缩 FASTQ
   和样本索引 CSV。
2. CSV 两列:`样本号,索引序列`;首行可为表头;索引仅允许 ACGTN(不区分大小写),
   必须**等长且唯一**;样本号唯一,且不能叫 `undetermined`(保留给未分配组)。
3. 提交后页面每 3 秒自动刷新;处理完成后按组提供 `样本_R1.fastq` / `样本_R2.fastq`
   下载、每组对数(含其中纠错对数)和处理日志 `demux.log`。

## 拆分规则

- 逐对核对:R1/R2/I1 三条记录的**读段号**(头部第一个空白前)必须一致,
  每条记录的**序列与质量长度**必须一致;三份文件记录数必须相同。
- 索引**精确匹配优先**;无精确匹配时,仅当**单碱基错配候选唯一**才纠到该样本;
  候选多个或无候选一律进 `undetermined`(未分配组)。
- 各组输出严格保持输入顺序;只输出 R1/R2(I1 仅用于判定)。

## 可靠性设计

- **不发布半套文件**:处理中的上传件与输出都在 `data/staging/<随机 token>/`;
  全部写完并生成日志后,在输出目录写入内容为本尝试 token 的 `.attempt` 归属标记,
  再经 `os.rename` **原子**移到 `data/published/<运行号>/`,同一事务写入计数并把
  运行置为 `published`。后段损坏、磁盘写失败等任何异常都会把运行标为 `failed`
  并清理半成品。
- **同号重试的清理互不误伤**:失败清理只回收**本尝试**的残留。暂存目录按随机
  token 彼此隔离可直接删;发布目录是按运行号共享的路径,清理时先把它原子挪到
  同卷 `.trash-<token>/` 隔离目录,凭 `.attempt` 标记判定归属——标记属于本尝试
  (或无标记的历史无主残留)才删除,属于同号重试新尝试的已发布文件则**原样还原**。
  新尝试发布前若发现同路径有旧残留,同样凭标记确认无主后才清走,有主绝不强删。
  这保证旧尝试的延迟清理不可能删掉新尝试已发布的文件(不会再出现"页面显示已发布、
  对数正常而下载 404"的状态不一致)。
- **进程中断恢复**:启动时把残留的 `processing` 运行标为 `failed`,凭 token 认领
  其暂存目录与可能来不及落库的发布目录;`.trash-*` 隔离目录、无主暂存与无主发布
  目录一并清扫(启动时本进程没有存活线程,不存在新尝试在用);已发布但文件缺失的
  运行标失败,保证"下载只见完整文件"。中断后用同一运行号重新提交即可安全重试。
- **重试与不可改写**:失败/中断的运行可用同一运行号重新提交直到完成;
  已发布运行同号提交返回 409,文件不会被覆盖。
- **计数可信**:计数与文件在同一次逐对扫描中产生,下载页只展示已发布运行的
  完整文件与对应计数;`.attempt` 为内部归属文件,不在下载文件名白名单内。

## 已知限制

- 仅支持未压缩的 4 行 FASTQ(不支持 .gz、不支持序列折行);上传 gzip 会以
  "不是纯文本"失败,需先解压。
- 单进程单 worker 运行(后台线程处理);不要起多个 uvicorn worker,
  否则中断恢复会误判在途运行。
- 每个样本 + 未分配组各占用 2 个输出文件句柄,样本数极多(数千)时需调高
  进程 fd 上限。
- 索引读长与样本索引长度不一致的读段进未分配组(不报错,见日志与计数)。

## 目录结构

```
app/
  main.py      # 路由、后台处理、原子发布、启动恢复
  demux.py     # 逐对流式 FASTQ 解析与拆分核心
  samples.py   # 样本索引 CSV 解析校验
  db.py        # SQLite schema 与连接
  config.py    # DATA_DIR 路径
  templates/   # 页面
tests/test_app.py  # 关键情形自测(pytest)
data/          # 运行期生成:app.db、staging/、published/
```
